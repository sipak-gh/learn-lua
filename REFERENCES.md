# References

This file lists the sources behind the facts in this course: the language rules, standard library
and FFI behavior, LuaJIT internals, version history, C library interfaces, and outside standards
each chapter relies on. Use it to check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the Internet
Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or changes). Where the Wayback Machine refuses a page, the archived
link points to [Software Heritage](https://www.softwareheritage.org/), an archive of public source code.
Links into the LuaJIT source code point at commit `a4c064539ea931274d407e1249b4bb575424a0f4`, the
version the course was checked against; links into other C sources point at a fixed release tag.
Program output shown in the chapters comes from running the course's own code and isn't listed here.
